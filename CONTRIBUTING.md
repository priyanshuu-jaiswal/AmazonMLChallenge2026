# Team Contribution Rules

1. Never modify `student_resource/dataset/` or commit the dataset.
2. Never commit submission outputs unless explicitly required.
3. Never delete historical experiments.
4. Give each experiment its own directory under `experiments/`.
5. Record objective, dataset/sample, methodology, parameters, results, runtime, and limitations for every experiment.
6. Do not silently change frozen methodology.
7. Do not overwrite historical experiment results.
8. Use descriptive Git commit messages.
9. Pull or rebase before collaborative work when appropriate.
10. Push completed work to a dedicated branch and use pull requests to merge into `main`.
11. Never force-push shared branches.
12. Never commit secrets, API keys, passwords, or credentials.
13. Run relevant validation/tests before merging and record the result.
